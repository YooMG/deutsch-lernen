# Deutsch Lernen — تثبيت التطبيق على iPhone

## الملفات المطلوبة
```
📁 deutsch-lernen/
├── index.html       ← الملف الرئيسي (Deutsch_Lernen_OPTIMAL_3_.html)
├── manifest.json    ← إعدادات PWA
├── sw.js            ← Service Worker (التخزين المؤقت)
├── icon-192.png     ← أيقونة صغيرة
└── icon-512.png     ← أيقونة كبيرة
```

---

## المزايا بعد التثبيت

| الميزة | التفاصيل |
|--------|----------|
| 📱 واجهة كاملة | يعمل بدون شريط Safari (Full Screen) |
| 💾 حفظ تلقائي | كل تقدمك محفوظ على الجهاز |
| ⚡ سريع | الصفحات تُحمَّل من الكاش |
| 🌐 متصل | يحتاج إنترنت لأول تشغيل فقط |
| 🔄 تحديث تلقائي | عند رفع نسخة جديدة تُحدَّث تلقائياً |

---

## ملاحظات iOS

- **iPhone 11, 12, 13, 14, 15, 16, 17** — كلها مدعومة
- يجب فتح الرابط من **Safari** فقط لإضافته للشاشة الرئيسية
- الـ localStorage يبقى محفوظاً حتى بعد إغلاق التطبيق
- لتحديث التطبيق: افتح Safari → الرابط مجدداً → الكاش يُحدَّث تلقائياً
